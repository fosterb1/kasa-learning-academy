# Kasa Video Classroom — bilingual, Twi-first education

## Upload a recorded lesson

1. Record and upload your Kasa lesson to your YouTube channel. Use a Public or Unlisted video and ensure embedding is allowed.
2. In YouTube Studio, review autogenerated captions or add your own. Export or create timestamped WebVTT (.vtt) or SRT (.srt) captions.
3. In Kasa Academy, visit /admin → Lessons and open the matching lesson.
4. Under Video Classroom, paste the YouTube URL, enter a title, and choose the spoken language.
5. For Twi/Akan and/or English transcript fields, import a local .vtt or .srt file. The file is read in your browser; it is stored as transcript text in PostgreSQL only when you save or publish.
6. Publish the lesson, then check the language switcher, search, caption highlighting, and timestamp jumps on its public page.

## What learners see

- YouTube video loads after a deliberate Play click rather than immediately when the page loads.
- Searchable Twi / Akan and English transcript tracks when supplied.
- Captions highlight as the video plays; clicking a line jumps to the corresponding timestamp.
- The existing Kasa code editor, quiz, and practice appear below the video.
- Transcript text works even when a visitor does not stream the video, making low-bandwidth access easier.
- Use the native CC button in YouTube when the video has a caption track.

## Transcription and limitations

**Automatic transcription is not implemented yet.** A YouTube URL alone cannot provide the academy with captions for arbitrary videos. The official YouTube caption-download API needs OAuth with permission to edit the video. Teachers can correct captions in YouTube Studio and import them into the academy.

Use human review for Twi and programming keywords (ka, ma, sɛ, awiei), as speech-to-text can be inaccurate.
Plain .txt files are accepted for readable transcripts, but only timestamped VTT/SRT files support synchronized navigation.
Host video on YouTube instead of uploading large media files to Neon or Vercel.

## Ghanaian design and future languages

The lesson player uses a green–gold–red accent, Twi-first copy, familiar Ghanaian examples and optional English explanations. The architecture can expand to Fante, Ga, Ewe, Dagbani and other Ghanaian languages.

## Development safeguards

Changing Payload collection fields requires a new, reviewed PostgreSQL migration. Test on Neon staging, run the migration on production before deploying the updated app, and verify the video editor. Never run migrate:fresh on the production CMS.
