# Kasa Academy teaching standard — Ghana-first, globally rigorous

## Benchmark and aim

Kasa should reach the depth of beginner-to-intermediate learning paths in the Python tutorial, MDN Learn JavaScript, freeCodeCamp and The Odin Project, **without claiming that Kasa already supports their entire language/API ecosystem**.

- Python tutorial: progressive concepts, worked examples, reference material and program structure.
- MDN: beginner explanations, skill tests, challenges and reference material.
- freeCodeCamp: progressive hands-on coding and assessed projects.
- The Odin Project: clear learning outcomes, reading assignments and increasingly complex builds.

References:
- https://docs.python.org/3/tutorial/
- https://developer.mozilla.org/en-US/docs/Learn_web_development
- https://www.freecodecamp.org/learn/

## Required structure for every Academy lesson

1. **Why this matters:** an accessible Ghanaian example and a concrete problem.
2. **Objectives:** at least two observable learning outcomes.
3. **Read:** concept explanation, vocabulary, input/output examples and pitfalls.
4. **Watch, when available:** instructor video and a reviewed Twi/English transcript. Video is optional.
5. **Trace:** predict output line-by-line before running code.
6. **Practice:** change one example, then implement a small independent task.
7. **Debug:** diagnose a common misconception and verify the fix.
8. **Check:** quiz plus mastery questions, with a real coding assessment in later stages.
9. **Extend:** apply the topic to a useful local problem or a broader concept.
10. **Review:** revisit previous concepts in later modules and capstone projects.

## Learner accessibility and inclusion

- Assume some learners use entry-level Android devices and metered mobile data.
- Keep the written learning path complete **without videos**.
- Include subtitles and transcripts for all newly produced recorded lessons when feasible.
- Use plain, precise English; add fluent-speaker-reviewed Twi for key terms, glossaries and audio. Never equate uncertain machine translations with verified Ghanaian language usage.
- Ghanaian stories should include school results, market sales, farming inputs, transport fares, mobile-money budgeting and community administration while remaining respectful of diversity.
- Avoid requiring paid accounts, cloud tokens or high-spec PCs for core lessons.
- Teach transferable computing principles, not only Kasa syntax.

## Content quality gates

- Every runnable example must be executed against the current browser runtime before claiming its output is correct.
- Preserve the learner's distinction between gross profit and net profit and between a demo and a production financial system.
- Mark unsupported language features as future topics, not existing Kasa capabilities.
- Request Ghanaian educator and Twi language review before publishing technical translations as authoritative.
- Do not overwrite CMS-authored lessons, teacher videos, transcripts, or published versions during content upgrades.
- Test responsive layout, keyboard navigation, no-video learning, and low-bandwidth reading.
- Record lesson author/reviewer, review date, language variant, and curriculum version in future CMS expansions.

## Curriculum expansion roadmap

**Phase 1 (implemented in repository):** 24 lessons with companion objectives, output tracing, misconceptions, guided assignments, independent assignments and mastery checks. This companion is code-backed and does not change existing CMS lesson records.

**Phase 2:** full textbook-style chapters with multiple worked examples and diagrams, especially control flow, types, data structures, debugging and algorithmic thinking. Store chapters in editable CMS fields only with additive migrations and tested data preservation.

**Phase 3:** graded coding activities with tests for output, boundary cases, bad inputs and explanations; then module reviews and mid-course assessments.

**Phase 4:** substantive end-to-end capstones including school-grade analyzer, market sales ledger, inventory decision tool, transport fare planner and savings tracker. Published assessment rubrics must distinguish demonstration quality from production security/reliability.

**Phase 5:** instructor-reviewed English/Twi bilingual transcripts, glossary support and optional downloadable reading packets; carefully test print layouts and offline behavior.

## Status disclaimer

The companion pages are a substantial first **teaching scaffold**, not a complete textbook, degree, accredited credential, or certification. A learner should not be told they have reached Python-level course coverage until equivalent chapter depth, graded practice, and authentic projects are delivered and independently reviewed.
